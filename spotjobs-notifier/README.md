# スポットジョブズ エリア通知

Gmail に届くスポットジョブズの通知メールのうち、**指定エリアを含むものだけ**をスマホにプッシュ通知します。
サーバー不要・無料（Google Apps Script ＋ ntfy）。スポットジョブズへの自動アクセスは行わないため、規約面でも安全です。

## セットアップ（約10分）

1. **スマホに ntfy アプリを入れる**（iOS / Android、無料）
   - 「＋」でトピックを購読。名前は推測されにくいもの（例: `spotjobs-k7f3q9x2`）にする
2. **Apps Script を作成**
   - https://script.google.com →「新しいプロジェクト」
   - `Code.gs` の中身を貼り付け
3. **設定を書き換え**（ファイル先頭の `CONFIG`）
   - `SEARCH_QUERY`: 通知メールの差出人に合わせる（例: `from:noreply@example.com`）
   - `AREAS`: 通知したいエリア（例: `['渋谷', '新宿']`）
   - `NTFY_TOPIC`: 手順1のトピック名
4. **動作確認**: 関数 `testPush` を実行 → 権限を許可 → スマホに通知が届けばOK
5. **自動実行開始**: 関数 `setup` を1回実行（以後、毎分チェック）

## 補足
- 処理済みメールには Gmail ラベル `spotjobs-checked` が付きます。
- メールが Gmail 以外に届く場合は、Gmail へ自動転送すれば使えます。
- 止めたいときは Apps Script の「トリガー」画面から削除してください。
